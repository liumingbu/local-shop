## 3. 判定

`DEV_COMPUTE_OK`：在Dot云电脑真实创建/运行/测试成功。

`DB_INTEGRATION_OK`：真实PostgreSQL条件和事务验证成功。
`WECHAT_RUNTIME_OK`：具有且实际使用微信运行条件；不能由前3项推出。
