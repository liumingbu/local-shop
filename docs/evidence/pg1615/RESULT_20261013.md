## 实际构建

已存在gcc14.2、make、Perl、OpenSSL3.5.7及zlib1.3.1。无需root，不更改系统安全/网络设置。

```sh
./configure --prefix="$PROJECT_TOOLS/postgresql-16.15" --without-readline --without-icu --with-openssl
make -j2
make install
"$PROJECT_TOOLS/postgresql-16.15/bin/postgres" --version
```

均退出0，版本输出`postgres (PostgreSQL) 16.15`。`PROJECT_TOOLS`表示开发者自行选择的项目专用工具目录；源码发布包已带生成文件，不需要运行bison/flex。
该构建采用libc排序、无ICU/readline；测试库`--no-locale --encoding=UTF8`，不等于生产排序规则已经确定。
