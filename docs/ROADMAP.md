# ROADMAP｜阶段、依赖与验收

这是计划，不是完成清单。实际状态以 `PROGRESS.md` 为准。里程碑不绑定未经验证的工期承诺。

| 阶段 | 范围 | 可验收产物 | 前置 |
|---|---|---|---|
| M0 | 环境与项目基线 | Dot实际环境报告、程序/测试、远端提交证据、文档PR | 仓库读写和main基线 |
| M1 | 最小可运行工程 | API健康、配置验证、迁移、开发身份、基础前端、测试与启动说明 | M0与文档基线已确认 |
| M2 | 首个业务闭环 | 老板代记→确认→备货→交付历史，两个租户隔离 | M1 |
| M3 | 商品和线上店面 | 分类、商品、多图、发布状态、公开只读店铺 | M2核心权限稳定 |
| M4 | 顾客与手机工作台 | 自助询货/需求、本人与商户流程、小程序代码 | M2、M3 |
| M5 | 微信接入与真实体验 | 登录、分享/码、图片、消息/隐私实测记录 | M4+外部条件 |
| M6 | 集成与交付 | 回归、安装/迁移、部署/备份恢复方案、验收包 | 核心模块集成；未决外部项显式说明 |

## M0 任务

M0-01：检查远端、工作区和真实授权，记录可见性但不更改。
M0-02：实测Dot终端、Git、运行时、文件操作、最小程序和测试；PostgreSQL能力单独记录。
M0-03：环境报告提交到独立分支，读取远端证据；无main先等待用户初始化。
M0-04：导入开发文档、用户审阅并合并。

通过标准：读写和运行证据可核对；不能只报告工具已安装。失败则明确阻塞，不能替换环境蒙混过关。

## M1 任务

M1-01：创建计划的monorepo、锁定真实依赖版本，建立配置样例与校验。
M1-02：API存活/就绪检查与错误处理，日志脱敏。
M1-03：数据库连接、租户/用户/成员迁移，隔离演示种子，不默认创建生产弱口令。
M1-04：开发身份模拟器及生产关闭保护测试。
M1-05：Web与原生小程序最小工程；真实可执行的类型/构建检查，缺少微信工具不伪装。
M1-06：基础测试、README命令；在功能分支提交PR。

通过标准：从干净检出按实际文档可安装、初始化并运行最小API，测试真实执行；迁移在真实PG验证；未具备的微信运行条件清楚列出。

## M2 任务

M2-01：服务端租户上下文和越权保护。
M2-02：老板代记及原始文本、自由明细、来源。
M2-03：确认/备货/自提/配送/完成/取消的状态机及事件。
M2-04：待办筛选和历史；Web最小工作台承载演示。
M2-05：两租户+两客户隔离、事务/幂等/并发测试。

通过标准：A的完整闭环可运行，B无法列出/查看/修改A；双击不重复，非法状态不能写入；重启后数据仍在。

## M3 任务

商品分类、多图排序/删除、发布状态、规格单位/参考信息、公开店铺；公开商品图与私有图片分离。测试跨租户分类引用、附件访问、商品改名后历史快照。

## M4 任务

顾客询货、商户答复、显式转需求；顾客自助提交和本人历史；原生小程序顾客页/老板工作台；店铺路由切换和草稿隔离。后台模拟身份下的接口测试与微信实际身份验收分开。

## M5 任务

由用户提供真实AppID/主体及安全配置渠道，验证微信登录、分享、扫码、网络与图片；检查消息模板、隐私、类目和审核材料。缺少条件时明确 `BLOCKED_EXTERNAL`，继续不依赖的开发。

通过标准分两级：接口适配器与模拟测试可完成；真实微信能力只有真测后才通过，不能提前把整个M5打勾。

## M6 任务

集成回归、负面权限测试、清洁安装、数据库迁移、备份恢复演练、单机部署文件、回滚、日志、已知问题、操作手册。生产连接和发布须另行授权。

完成定义：
- `DEV_REVIEW_READY`：核心业务可复現运行、测试通过、源码已推送，真实微信待测项明确。
- `PILOT_READY`：开发者工具/真机、身份和关键分享网络等必需项已验证，发布合规与运行条件经用户确认。
- `PRODUCTION_RELEASED`：仅在授权部署且微信发布证据真实存在时使用。

不得把 `DEV_REVIEW_READY` 写成“已上线”。

## PR依赖与持续推进

每个可验收模块独立PR，不要求每个子任务单独PR。需要上一PR内容的后续任务在其未合并时等待，或执行无依赖事项。用户于2026-10-13已授权Dot自查测试后合并本项目常规PR；不启用自动合并，不扩大生产/费用权限。未真实合并前不能假装依赖已进入main。

## 2026-10-14后续授权

在已有工程上依次交付A页面与交互、B日常待办/历史闭环、C正式身份代码和模拟外部微信隔离测试、D参考规模性能/启动升级/源码交付。只做一次有限浏览器排障。AppID暂缺不阻塞身份适配器代码；平台若需新增独立账号体系先确认最小方案。每工作包报告实际入口、被测SHA、PR与缺失验证；不自动提升PILOT_READY。
