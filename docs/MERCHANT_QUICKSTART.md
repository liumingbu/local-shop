# 商户上手（开发验收范围）

仅使用合成数据。真实微信/浏览器视觉尚未验收，不能当作已上线试点。

## 开店准备

沿用平台定向邀请、本人接受和审核授权后进入工作台。Web选择「开店准备/CSV导入」；原生商户工作台选择「开店准备」。步骤根据服务端真实店铺配置/分类/商品计算，不需重复注册。

1. 「店铺资料/交付说明」填写店名、经营联系信息、自提地址及允许的交付方式。Web在「记单与待办」的店铺资料中编辑；原生进入已有店铺资料页。
2. 商品可稍后补充；「稍后完善，直接记单」不要求建立商品库，电话/微信/到店需求可先保留原文。
3. 「店内预览」只展示授权店铺的真实配置和最多20件未归档商品，不等同微信渲染/公开发布。需要发布时通过已有资料/商品维护明确设置。
4. 微信分享/二维码显示待接入，不生成伪造微信码。

## CSV 草稿导入

Web「开店准备/CSV导入」下载UTF-8模板。固定8列：商品名称、分类、规格、单位、参考价格、供货说明、排序、商品介绍。单位是实际单位文字（如斤/盒/袋/件），不可空；不自动换算。参考价可空，非负最多两位小数，不是应付金额。供货说明仅常备/待确认/暂缺；排序0—100000。

最多200行，默认512KiB（可通过CSV_IMPORT_MAX_BYTES降低，不超过硬上限），每格最长4000字符且各字段遵循商品模型更小的长度限制。逗号、引号和换行按CSV规范引用。只接受CSV文本，不接Excel宏/压缩包，不执行公式或抓取远程图片。

选文件或粘贴CSV → 解析并预览 → 逐行检查无效/疑似重复与拟新增分类 → 明确勾选允许范围 → 确认导入范围 → 创建草稿。不会自动发布、按同名覆盖或删除已有商品。同名不同规格/单位不会被当作同一商品；同名同规格同单位只作为疑似重复，需明确允许另建。

「停止后续行」不撤销已经成功的一行。离开页面、网络中断或结果不确定时，从本店已有导入任务重新读取，核对SUCCESS后继续未完成行；不重新导入整份文件来“补漏”。成功行不会重复创建。失败行保留原因；修改文件时只整理仍需导入的行，再新建预览。重复导入同内容仍会提示已存在的疑似重复，幂等键不能替代批次核对。

「下载结果/错误清单」为显示用文本CSV，各格加单引号并整体双引号转义。用文本列方式打开，不移除保护、不另存后执行公式；该显示清单不是直接重导模板。电子表格再保存可能改变保护，应核对软件行为。原CSV不作为公开下载文件保存，任务原始单元格/结果仅本店授权接口可读。

不要把真实客户资料、密码、令牌或私图放进商品CSV。误导入通过已有商品归档处理，不自动永久删除。

备货/沟通指南将在F/G实现后追加；当前不得据此宣称F/G已完成。

CSV防注入说明参考[OWASP CSV Injection](https://owasp.org/www-community/attacks/CSV_Injection)（2026-10-16查阅）：导出按文本防护并转义分隔符，不承诺所有电子表格软件及再保存后的处理方式都安全；不可把显示用导出当执行公式或重导模板。
