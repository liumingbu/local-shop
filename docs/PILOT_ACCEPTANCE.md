# 商户试点核对与反馈（E—H授权范围）

本表是合成验收和后续人工试用的共同清单，不代表已有真实商户试用、微信审核或生产部署。实际执行状态与SHA见PROGRESS.md、TESTING.md和evidence。运行环境仍是Dot临时开发电脑。

## 实际操作路线

1. 沿用START_HERE/DELIVERY中现有启动方式，仅在受控开发环境进入Web工作台；正式身份代码不借用演示身份。真实AppID暂缺时不宣称正式微信登录可用。
2. 平台邀请、本人接受、平台审核后进入店铺。Web「开店准备/CSV导入」或原生「开店准备」核对真实资料；可以跳过商品库先记电话需求。
3. 下载CSV模板，UTF-8固定8列，最多200行/512KiB。预览错误、重复和新分类，明确确认后逐行创建草稿。导入不会自动公开商品。断网后读回任务，再用原提交续传。
4. 日常「记单与待办」或原生工作台确认需求并安排备货。Web「今日备货/交付清单」切换按单/按商品；未确认、已取消和已完成默认不参与，取消意向和自由文本单列核对。不同商品ID、规格或单位不合并。
5. 默认备货CSV/TEXT/PRINT不带完整电话地址或内部备注；配送/自提清单仅在明确勾选用途后包含必要联系信息。生成/打印不是完成交付。旧清单遇到版本变化需刷新。实际纸面分页未验收。
6. 「站内更新」只标记本人看过；待办仍在原工作台。商户详情里完成真实电话/微信联系后明确登记结果。仅复制摘要不记录联系成功、不自动发送。
7. 老板明确标记备货、待取/配送、完成后，从历史查询；不要把内部备注或私图分享到公开页面。
